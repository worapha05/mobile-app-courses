# Flutter Mastery Bootcamp

หลักสูตร Self-Learning Flutter & Dart แบบ Zero-to-Expert แบ่งเป็น 3 ระดับ:

## โครงสร้าง

```
flutter-mastery-bootcamp/
├── 01-beginner/       ← ระดับ Beginner
│   ├── pubspec.yaml   (package: flutter_mastery_bootcamp_beginner)
│   ├── lib/           ← โค้ด Dart
│   ├── test/          ← Unit/Widget tests
│   ├── example/       ← Flutter app สำหรับรัน demo
│   ├── README.md      ← ทฤษฎี
│   └── LAB.md         ← โจทย์ + เฉลย
├── 02-intermediate/   ← ระดับ Intermediate
│   ├── pubspec.yaml   (package: flutter_mastery_bootcamp_intermediate)
│   ├── lib/
│   ├── test/
│   ├── example/
│   ├── README.md
│   └── LAB.md
├── 03-expert/         ← ระดับ Expert
│   ├── pubspec.yaml   (package: flutter_mastery_bootcamp_expert)
│   ├── lib/
│   ├── test/
│   ├── example/
│   ├── devops/        ← Fastfile + GitHub Actions
│   ├── README.md
│   └── LAB.md
└── README.md          ← ไฟล์นี้
```

## เริ่มใช้งาน

```bash
cd 01-beginner
flutter pub get
flutter test
```

```bash
cd 02-intermediate
flutter pub get
flutter test
```

```bash
cd 03-expert
flutter pub get
flutter test
```

## Learning Path

| Level        | Package                                 | โค้ด                   |
| ------------ | --------------------------------------- | ---------------------- |
| Beginner     | `flutter_mastery_bootcamp_beginner`     | `01-beginner/lib/`     |
| Intermediate | `flutter_mastery_bootcamp_intermediate` | `02-intermediate/lib/` |
| Expert       | `flutter_mastery_bootcamp_expert`       | `03-expert/lib/`       |
